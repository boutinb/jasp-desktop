    Text QML Type

    A JASP-themed text display element. More...

    • List of all members, including inherited members

    Detailed Description

    Wraps Qt's Text with the JASP default font and color scheme. Text color automatically adjusts when the control is disabled.

    Note: Text does not bind to R options. It is a display-only control.

    Example

    Text { text: qsTr("Note: values are log-transformed.") }
